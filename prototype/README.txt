HOW TO RUN
1. Unzip the whole folder (don't open files from inside the zip).
2. Double-click index.html (needs internet: Tailwind, fonts and images load from CDNs).
   Better: run a local server ->  python -m http.server 8000  -> open http://localhost:8000
Pages: index (desktop home), mobile (mobile home), menu (mobile menu), shop, product, bag.
